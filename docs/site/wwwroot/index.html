03 / C İSTEMCİ + C++ API

Uygulamana
bağla.

`mdcompiler-client` compiler sürecini shell kullanmadan başlatır ve çıkış kodunu çağırana döndürür.

Cİstemciyi kullan
mdcompiler-client ./build/mdcompiler \
  run examples/hello.cpp \
  --compiler clang++ \
  -- --verbose

İstemci `--protocol` seçeneğini otomatik ekler. Windows'ta `build\Release\` altındaki `.exe` yollarını kullan.

C++Derleyici bilgisini al
#include "compiler.hpp"
#include <iostream>

int main() {
    const std::filesystem::path source{"main.cpp"};
    const auto language = mdcompiler::languageFromSource(source);
    const auto compiler = mdcompiler::resolveCompiler(language);
    if (compiler.empty()) return 1;

    mdcompiler::CompileOptions options;
    options.standard = "c++17";
    const auto command = mdcompiler::buildCommand(
        compiler, language, source, "build/main", options
    );
    std::cout << command << '\n';
}

Bu C++ API proje içidir; uygulamandan süreç başlatırken argüman vektörü kullanan platform API'sini tercih et.
